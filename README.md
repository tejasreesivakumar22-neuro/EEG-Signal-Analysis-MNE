# EEG Signal Analysis Using Python and MNE-Python

## Project Overview
This project explores basic EEG signal processing using Python and MNE-Python as part of my learning journey in computational neuroscience.

## Objectives
- Visualize EEG signals.
- Apply band-pass filtering to EEG data.
- Understand event-related epoching and baseline correction.
- Explore mu- and beta-band activity.
- Interpret statistical results carefully.

## Tools and Technologies
- Python
- MNE-Python
- NumPy
- Pandas
- Matplotlib
- JupyterLab

## Methods
The workflow includes EEG visualization, signal filtering, epoch extraction, baseline correction, and frequency-band analysis, depending on the completed analysis.

## Results
Results and visualizations will be added after completing and verifying the analysis.

## Limitations
The interpretation depends on the dataset, preprocessing choices, sample size, and statistical methods. Any practice or simulated data will be identified clearly.

## Learning Outcomes
This project helps develop practical skills in EEG preprocessing, Python-based data analysis, and computational neuroscience.
